VAP’ & MOI PRO V50 — ENREGISTREMENT ROBUSTE

Cette version corrige le traitement d'erreur de save():
- la vérification de l'écriture locale est séparée du rafraîchissement de l'interface, afin qu'une erreur d'affichage ne soit pas signalée à tort comme un échec de stockage ;
- en cas de véritable échec d'écriture, l'application affiche le nom et le message de l'erreur pour aider au diagnostic ;
- une sauvegarde JSON de secours est proposée au téléchargement si le navigateur le permet ;
- la valeur précédemment enregistrée est restaurée lorsque possible ;
- titre, manifeste et cache harmonisés sur V50.

IMPORTANT : si le navigateur refuse réellement l'écriture (quota plein, permission ou stockage inaccessible), ce correctif ne peut pas forcer l'enregistrement. Ne considérez pas une vente comme enregistrée si elle n'apparaît pas dans l'historique. Sauvegardez les données avant toute publication.

Clé de stockage conservée : vapetmoi_fidelite_v1.
Contrôles effectués : syntaxe JavaScript et intégrité ZIP. Tests sur téléphone/données réelles non effectués.
